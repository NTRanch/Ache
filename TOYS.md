# Lovense toy catalog

The current Lovense developer-program toy lineup, as listed by
Lovense (product pages under lovense.com/p/Dev_*). 24 devices.

Function support per device is defined by the Standard API
reference: a toy answers only the functions it physically has,
and unsupported functions return error 403. Query a connected toy
with GetToys and read its shortFunctionNames / fullFunctionNames
rather than assuming capabilities from this list.
